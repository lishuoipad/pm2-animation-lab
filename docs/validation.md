# 验证范围与复现边界

原25项实录实验共15,122帧，逐像素一致；源码步总数1,242，544帧使用显存复制模型。完整统计见`coverage.json`，其中不包含原作帧、输入随机带、录像路径或存档。

这些数据证明指定录像窗口能由固定源码及兼容输入连续重建。它们不证明任意年龄、等级、事件、成败组合、其他源码版本或硬件都无差异。剑术与格斗术为5天选区；其余为10天。部分课程尾端是明确选定的观察片段，不用于推断整个游戏末帧停留。

“时间一致”包括每个原生帧的有理数PTS和结束边界。GIF/MP4累计边界舍入不超过5ms。连续相同画面内部的时间边界不可见，时钟标记为capture-calibrated；显存复制进度同样来自实录约束，均不是独立预测。

测试分为：

1. 无原作文件的自动回归：原创内存图像、合成脚本、哈希、时间算术、排序、文件隔离、错误输入和命令行契约。CI执行这部分，并明确显示可选测试的skip数。
2. 可选固定源码回归：设置`PM2_SOURCE_ROOT`后，检查真实源码解释语义、日历与特殊入场；不需要提交原作源码。
3. 本机原生媒体回归：使用自己的完整录像索引和请求逐项运行`pipeline --playback-directory`。任何失败都必须保留，不得把CI成功当成原作视觉验收。

安装包还必须通过资源加载、包内导入、命令入口及公开文件检查。独立版沿用原计算和核验流程；路径配置与包结构变化不能放宽像素、顺序、哈希和时钟门槛。
